# Employee Directory

Una aplicación web creada con React y Vite que muestra un directorio corporativo de empleados consumiendo la API de Random User.

## Características principales
- Interfaz moderna y elegante en modo oscuro (Dark Mode).
- Tarjetas de empleados con avatar de iniciales, nombre, ubicación y datos de contacto.
- Diseño completamente responsivo utilizando CSS Grid.
- Manejo de estados de la interfaz: Pantalla de inicio, Carga (Loader) y Lista de resultados.

## Tecnologías utilizadas
- React (Hooks: useState, useEffect)
- Vite
- CSS3

## Instalación y Uso local
1. Clona este repositorio en tu equipo local.
2. Abre la terminal en la carpeta del proyecto y ejecuta `npm install` para instalar las dependencias.
3. Ejecuta `npm run dev` para iniciar el servidor de desarrollo.
